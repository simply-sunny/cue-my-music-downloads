Install

For Minecraft 26.3 on Fabric or Quilt. Java 25. Client-side only.

  1. Install Fabric Loader or Quilt Loader.
  2. Install Fabric API.
  3. Install Cue My Music 1.4.0 or newer.
  4. Install yt-dlp and ffmpeg with the command below.
  5. For Spotify links, install spotdl: pipx install spotdl.
  6. Put the jar from Releases in mods.
SystemCommand
macOSbrew install yt-dlp ffmpeg vorbis-tools
Windowswinget install yt-dlp.yt-dlp Gyan.FFmpeg
Linuxpipx install yt-dlp, and ffmpeg from your package manager

Tools are found on PATH and in /opt/homebrew/bin, /usr/local/bin, /usr/bin, /snap/bin, ~/.local/bin and WinGet's Links folder.
