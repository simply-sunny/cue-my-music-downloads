Documentation / Install

Install

Recommended: Prism Launcher

  1. Create or select an instance with the Minecraft version and loader listed below.
  2. Open Edit → Mods → Download Mods. Find the mod on Modrinth or CurseForge where it is listed, and install its required dependencies.
  3. If the mod is not listed there, download its JAR from the project’s release page and add it to the instance’s mods folder.
  4. Complete the project-specific setup below, then launch the instance.

Downloads

  • GitHub Releases

Client-side only.

  1. Install Cue My Music 1.3.0 or newer, with its requirements.
  2. Install yt-dlp and ffmpeg. The add-on doesn't download them.
System Command
macOS brew install yt-dlp ffmpeg vorbis-tools
Windows winget install yt-dlp.yt-dlp Gyan.FFmpeg
Linux Your package manager, such as sudo apt install yt-dlp ffmpeg. Distro yt-dlp packages are often too old for YouTube; pipx install yt-dlp gets the latest.
  1. Put the jar from Releases in mods. For Spotify links, also install spotdl: pipx install spotdl (or pip install spotdl).

The add-on looks for all three tools on your PATH, and in /opt/homebrew/bin, /usr/local/bin, /usr/bin, /snap/bin, and ~/.local/bin (on Windows, WinGet's Links folder), since launchers often don't pass on the shell's PATH. A tool installed while the game is running is found on the next download. spotdl is optional; only Spotify links need it.
