Install

  1. Cue My Music 1.3.0+ with its requirements.
  2. yt-dlp and ffmpeg (the add-on doesn't download them), and for Spotify links spotdl (pipx install spotdl):
    SystemCommand
    macOSbrew install yt-dlp ffmpeg vorbis-tools
    Windowswinget install yt-dlp.yt-dlp Gyan.FFmpeg
    LinuxYour package manager for ffmpeg, and pipx install yt-dlp: distro yt-dlp is often too old for YouTube.
  3. The jar from Releases in mods.

Tools are found on PATH and in /opt/homebrew/bin, /usr/local/bin, /usr/bin, /snap/bin, ~/.local/bin and WinGet's Links, since launchers often drop the shell's PATH. A tool installed mid-game is picked up on the next download.
